# LeadFlow CRM

A Full Stack Client Lead Management System built using React, Node.js, Express.js, and MongoDB.

## Features

* Admin Login
* Add New Leads
* Search Leads
* Update Lead Status
* Add Follow-up Notes
* Edit Notes
* Delete Leads
* Lead Analytics Dashboard
* Source Tracking
* Timestamp Tracking

## Tech Stack

### Frontend

* React.js
* Axios
* CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## Project Structure

backend/
frontend/

## Installation

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
